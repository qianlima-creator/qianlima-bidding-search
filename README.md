# 千里马招标网 · 乙方宝标讯查询 Skill

面向支持 Agent Skills（`SKILL.md`）的智能助手，通过自然语言查询招投标信息、发现采购商机、跟进项目进展，并开展招投标视角的企业分析。

**Skill 名称：** `qianlima-bidding-search`  
**版本：** `v1.0.4`  
**功能基准：** 千里马主 Skill `v3.4.7`  
**账号与 API Key：** [千里马账号平台](https://ai.qianlima.com/?source=b21e4d10ecdea318b517c48a)

## 功能

| 能力 | 可查询内容 |
| --- | --- |
| 标讯查询 | 招标、中标、成交、合同等公告；按业务关键词、地区、时间及支持的筛选条件检索 |
| 指定单位标讯 | 查询指定采购方、招标单位、中标单位或代理机构相关公告 |
| 采购意向 | 查询采购意向，发现前期采购线索 |
| 临期项目 | 查询合同到期与潜在续约商机 |
| 项目跟进 | 查看详情、普通项目正文、附件、进展与来源链接 |
| 企业情报 | 查找企业候选，查询中标记录、合作甲方、合作供应商、地区分布、竞争对手及工商信息 |
| 企业联系方式 | 用户明确需要时查询企业联系人或电话 |
| 账号用量 | 查询可用积分和原文月度用量、剩余次数等接口实际返回信息 |

## 开始使用

### 1. 准备环境

- 支持加载 `SKILL.md` 的智能助手。
- Python 3.10+。普通标讯基础列表支持免注册、免 Key 免费查询。
- 完整公告、附件、联系方式、采购意向、临期项目及企业情报等深度能力需个人 API Key，以及相应账号权限和积分。

### 2. 免费开始，按需登录

直接描述地区、时间和业务关键词，即可查询免费基础列表；每组最多查看前 10 页、300 条。免费次数额度与请求频率限制分别按实际响应处理。

新用户注册可获赠500积分，如需登录或注册，直接说“我要登录”即可，按手机号验证码流程办理。完整公告、附件及联系方式需登录后使用积分查询。混合需求先交付免费能够满足的部分，再说明未完成的深度内容。

已有个人 Key 默认使用正式查询；主动要求免费时使用免费列表，查看深度信息仍按授权使用积分。明确积分不足且免费能力可满足全部或部分需求时，交付免费结果并说明实际积分状态；不把无效 Key、限频或服务失败当作积分不足。

### 按需获取并配置 API Key

可在会话内按 Skill 的文字引导完成手机号验证码注册／登录。开始前检查当前凭据与宿主可用的配置、加载能力；取得 API Key 后，由宿主 Agent 按配置规则保存、私有读回核对，并加载到查询进程。取得 Key 不等于配置成功，只有保存、读回和加载均完成后才能确认配置成功；实际跨会话复用能力取决于宿主。

也可通过网站获取 Key：

访问 [https://ai.qianlima.com/?source=b21e4d10ecdea318b517c48a](https://ai.qianlima.com/?source=b21e4d10ecdea318b517c48a) 注册或登录，获取 API Key，并查看价格、积分、充值与地区权限。

在启动智能助手或调用脚本的环境中设置 `QIANLIMA_API_KEY`。例如，在 macOS / Linux 终端中：

```bash
export QIANLIMA_API_KEY="替换为你自己的API_Key"
```

该设置仅对当前终端及其启动的进程生效；使用桌面客户端时，请通过客户端支持的环境配置方式提供变量。

请勿将真实密钥提交到 GitHub、写入 README 或放入公开截图。Skill 文件与接口数据服务的授权、费用是分别管理的，具体计费与额度以账号平台为准。

### 3. 安装 Skill

下载并解压本仓库，找到根目录下的 `qianlima-bidding-search/` 文件夹，将**整个文件夹**导入所用客户端的 Skill 安装位置，保留内部结构。

对于使用 `~/.codex/skills/` 作为个人 Skill 目录的本地 Codex 环境，可在仓库根目录执行：

```bash
mkdir -p ~/.codex/skills
cp -R qianlima-bidding-search ~/.codex/skills/
```

如果已有同名 Skill，请先备份旧版本，再替换。安装后按客户端要求重新加载 Skill 或重启客户端。其他支持 Agent Skills 的客户端，请按其安装说明导入。

### 4. 用自然语言查询

```text
使用 $qianlima-bidding-search 查询近7天广东省物业服务招标项目。
```

无需自行填写接口参数或内部地区编号。使用支持自动选择 Skill 的客户端时，也可以直接描述查询需求。

## 使用示例

### 查标讯与采购商机

```text
查询近30天江苏省的消防设备招标项目。
查询500万元以上的物业项目，排除保洁。
查北京大学作为采购方发布的标讯。
查某家公司作为中标单位的公告。
查询医疗设备采购意向。
查找物业类临期项目和潜在续约机会。
```

### 连续追问与项目跟进

```text
继续看下一页。
把地区改成浙江，其他条件不变。
查看刚才第2条公告的详情。
总结第1条公告的正文。
获取第1条公告的附件和原文链接。
查看这个项目的招中标进展。
```

连续追问会承接对应结果集和有效筛选条件。普通项目、采购意向、临期项目支持的详情与资源不同：正文、附件和时间线能力用于普通项目，其他类型以各自接口能力为准。

### 企业分析与账号用量

```text
查询某公司相关的中标公告。
分析某公司的合作甲方与合作供应商。
查询某公司的采购与中标地区分布。
查询某公司的竞争对手。
查询某公司的企业电话。
查看当前可用积分和原文月度剩余次数。
```

企业名称为简称、品牌或集团泛称时，Skill 会先列出候选，由用户确认主体。企业联系方式仅在用户明确需要时查询。

## 查询范围与结果说明

- 项目搜索需要有效关键词；完整单位名称或项目编号也可用于相应位置的检索。只有地区或分类时，需要补充最小必要关键词。
- 北京、上海、天津、重庆支持区县筛选；香港、澳门、台湾暂不支持区县筛选。涉及受限地区的精确区县请求时，先说明实际范围并确认是否接受整体范围。
- 普通项目时间范围最多 3 个日历年：日期包含周年边界日全天，明确时分秒时按周年时刻比较。
- 采购意向的发布时间和预计采购时间分别最多 3 个日历年；月份差最多 36 个月，包含边界月。不跨两个时间字段比较跨度；未传预计采购时间时默认未来第 1 至第 3 个月。
- 临期项目的服务到期范围最多 5 个日历年，包含周年边界日；闰日按目标年 2 月末日处理，合同期限枚举保持不变。
- 时间范围超限时请用户调整，不自动截短或拆分查询。
- 查询事实来自当次接口响应；无权限、失败或零结果时，会说明实际情况。
- 详情中的空值按 Skill 规则显示为“未公示”；具体信息以公告、附件及返回的来源链接为准。
- 正文与原文链接属于不同资源，可明确指定需要哪一种。
- 网络或计费结果不明确时，不自动重复可能计费的调用。
