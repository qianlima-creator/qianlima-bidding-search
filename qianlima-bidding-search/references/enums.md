# 千里马枚举值

将用户自然语言条件转换为接口参数时使用以下 ID。字段名和 ID 必须保持接口原样。

## 采购单位类型

```json
{
  "1": "医疗",
  "2": "政府",
  "3": "学校",
  "4": "公安",
  "5": "金融企业",
  "6": "部队",
  "7": "通信运营商"
}
```

## 关键词匹配方式

用于采购意向和临期项目搜索的 `keywordsSearchType`。

```json
{
  "1": "任一关键词命中（OR）",
  "2": "全部关键词命中（AND）"
}
```

## 项目阶段

父类 3 的“中标公告”实际是结果公示，含废标、流标、开标、候选人、中标通知、合同。泛称中标／成交结果选择 11＋12，不能直接全选父类。

采购意向不属于标讯项目阶段，不使用 `99`；采购意向查询统一调用 `/search/purchase`。

    }

      "4": "重新招标"
    }
  },
  "2": {
    "name": "招标变更",
    "children": {
      "5": "信息变更",
      "6": "答疑公告"
    }
  },
  "3": {
    "name": "中标公告",
    "children": {
      "7": "废标公告",
      "8": "流标公告",
      "9": "开标公示",

## 匹配范围

用于普通标讯、采购意向和临期项目搜索的 `matchScopes`，支持多选，格式为数字数组。
`1` 表示全部，固定搜索标题、正文和附件；其他值只搜索对应位置。正文／附件中可以包含单位、联系人、编号、标的物；明确角色查询仍分别用采购单位4、中标单位5、代理6。

```json
{
  "1": "全部（标题+正文+附件）",
  "2": "标题",
  "3": "项目编号",
  "4": "采购单位",
  "5": "中标单位",
  "6": "代理机构",
  "7": "联系人",
  "8": "正文",
  "9": "标的物",
  "10": "附件"
}
```

## 采购分类

用于普通标讯搜索的 `procurementCategories`。

```json
{
  "0": "其他",
  "1": "货物",
  "2": "工程",
  "3": "服务"
}
```

## 资金来源

用于普通标讯搜索的 `fundsSources`，支持多选。

```json
{
  "1": "财政资金",
  "2": "专项资金及债券",
  "3": "银行贷款",
  "4": "投资/融资",
  "5": "单位自筹"
}
```

## 排序方式

```json
{
  "1": "时间倒序",
  "2": "综合排序",
  "6": "相关性倒序"
}
```

## 企业统计排序方式

用于企业合作供应商、合作甲方、采购地区分布和中标地区分布接口。

```json
{
  "1": "按次数倒序",
  "2": "按金额倒序"
}
```

## 采购方式

“竞争性谈判”与“竞争性磋商”在本接口均为 2；“询价”为 4。

```json
{
  "0": "公开招标",
  "1": "邀请招标",
  "2": "竞争性谈判/磋商",
  "3": "单一来源",
  "4": "询价",
  "5": "其它",
  "6": "电子卖场"
}
```

## 报名状态

用于普通标讯搜索的 `registrationStatus`。0 要求报名时间有值且未结束，空时间不匹配；不保证已开始报名或投标未截止。未传不限。

```json
{
  "0": "报名时间未结束",
  "1": "报名时间已结束"
}
```

## 二值筛选

以下字段使用相同的 `0/1` 编码。字段不传表示不限制该条件。

```json
{
  "0": "否",
  "1": "是"
}
```

适用字段：

- `hasAnnex`：是否包含附件
- `hasAgency`：是否有代理机构
- `hasBiddingPhone`：是否有招标联系电话
- `hasWinningPhone`：是否有中标联系电话

## 临期项目合同周期类型

用于 `contractPeriodType`，后端会转换为工期天数范围查询。

```json
{
  "1": "1年以下，小于360天",
  "2": "1年，360-550天",
  "3": "2年，551-900天",
  "4": "3年，901-1300天",
  "5": "5年，1400-2000天",
  "6": "5年以上，大于2001天"
}
```

## 企业联系电话类型

用于 `phoneType`。

```json
{
  "1": "手机",
  "2": "座机"
}
```

## 地区

地区编号与规范完整名称统一见 `area.json`；使用本地 `area` 解析一个或多个地区，仅 `resolved` 的参数可查询。调用规则见 [地区](../SKILL.md#地区)。
