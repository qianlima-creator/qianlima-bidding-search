# 常见问题与失败处理

优先按脚本 `user_message/warnings` 说明用户请求是否成功，保留本次业务错误的实际原因。内部错误码、参数和堆栈不直接展示。

| 情况 | 处理 |
| --- | --- |
| 缺少或无效 API Key | 缺少时原样展示 `prepare.guidance`；明确无效时提供会话登录或其他 Key，见 [账号接入](account-access.md)，不回显密钥 |
| 正常零结果 | 说明当前条件范围内未找到，不查权益、不编造项目；按普通项目规则决定是否一次加正文补查；明确限制优先，其他扩大按授权处理 |
| 地区权限不足 | 保留地区受限原因；余额足够不证明地区可用 |
| 积分不足或原文月度次数耗尽 | 使用已有的一次诊断补充可用积分或原文剩余次数、重置时间 |
| 网络、结算超时、请求处理中 | 说明本次状态；不自动重复计费调用 |
| 频率限制 | 停止连续提交，建议稍后再试，不推断余额或调用额度 |
| 参数无效 | 原话明确而 Agent 填错字段、枚举、日期或单位时自行修正；只有真实业务歧义才询问，不把错误推给用户 |
| 正文未采集或为空 | 明确本条正文暂不可用，不拿空文本宣称读取成功 |
| 某资源失败、其他资源成功 | 交付成功部分，保留失败原因，不重放成功调用 |
| 状态缺失、过期、损坏或不可写 | 已知 ID 直接读；完整原条件与准确页码用上下文恢复；只澄清缺项，不自动重查。清理/保存失败照常交付 API 成功数据，不重放 |
| 对象有多个候选 | 请用户明确列表/序号/标题，不批量取详情猜测 |

完整错误码见 [API](api.md)。诊断只补充事实，不覆盖原失败；正常零结果、网络、认证和参数错误不触发额外诊断。

## 注册／登录与配置失败

- `stage=legal` 表示脚本未能取得登录接口必填参数，尚未提交验证码；说明登录暂未发起，不让用户补版本、不误报验证码错误、不自动重发短信。

- 没有实际配置的 Key 时直接首次配置，不询问替换；仅用户明确要求换号或换 Key 才进入更换流程。配置过滤值 `exclude`／`include` 不代表已有 Key，不拿去查询。

- 手机号格式错误不发码；发码失败、受限和超时分开说明。超时结果未确认，不断言失败，不编造等待时间，不自动连续重发。
- 验证码错误或过期允许重新输入或主动重发；反馈必须包含实际原因、当前状态和可用入口，具体按[结果反馈规则](account-access.md#结果反馈规则)。登录被拒绝、Key 获取失败按实际环节说明，不额外创建、重置或启用 Key。
- `credential_available` 只表示工具已返回 Key，账号脚本的 `configuration_written=false` 不表示登录失败。保存授权和替换条件已满足时，Agent 立即按用户提供 Key 的同一规则保存、读回和落实后续加载，不停在登录成功、不要求重发 Key 或配置指令。
- 保存失败使用已取得的 Key 处理配置，不自动重复登录或发短信；写入结果未知先核查，不盲目覆盖。按 Agent 实际配置结果区分未写入、已写入、结果未确认；加载失败不报当前可用。配置来源冲突、版本变化或未确认替换时停止覆盖。
- 余额失败说明“当前剩余积分暂未确认”，不否定登录或配置；临时 logout 失败不撤销 Key，也不声称已注销。
- 取消停止后续动作，不承诺撤销已提交请求；未写入保留旧值，已写入如实说明，不自动回滚或跨调用恢复。除缺 Key／明确无效外，原查询错误规则沿用。

## 会话文字接续

- 本版暂停登录卡片。直接按[账号接入](account-access.md)展示文字引导，不创建 HTML、引导文件或侧栏预览，不要求安装桥接服务。
- 手机号、六位验证码和“重新发送”均直接回复会话。验证码保留前导零，按当前号码绑定交给后台判断，不回显验证码。
- 没收到验证码时核对本次提交的完整手机号，用户明确要求重发后才执行；以实际成功回执检查发送间隔，不编造倒计时。
- 旧会话提交仍须核对当前号码与完成／取消状态；上下文有歧义时先澄清，不重放已完成或取消的流程。

## 字段和资源不支持

已知数据源决定可用详情与资源；`detail --id` 默认普通项目，采购意向/临期明确对应 `--result-type`，不从旧名单猜其他来源。源不明只澄清来源。普通项目支持正文、附件、时间线；采购意向仅自身详情中的采购需求和详情页；临期使用自身详情和来源链接。支持检索某位置，不证明详情返回该位置字段。

支持字段返回 null 可说未披露或无法确认；不支持的字段应直接说明能力边界，不假装“未公示”。普通详情中的 `bidingEndTime` 是标书获取截止，`biddingEndTime` 是投标截止。

空结果不建议不存在的普通标讯“不限时间”，不机械将中标通知＋合同放宽为含废标／流标的整个结果类，也不自行删必需概念或扩排除词。

## 外部信息

名称消歧优先 `search-company`；必要外部核验只核实名称。用户明确要求背景分析或接口失败后明确要求 WebSearch，可单独处理公开信息，标注为互联网补充，不替代千里马结果或绕过权限。失败提示不主动引导外部搜索补受限数据。
