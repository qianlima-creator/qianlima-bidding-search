# 账号入口与访问限制

注册、登录、API Key、价格、充值、地区权限和账号管理的唯一入口为 [千里马账号平台](https://ai.qianlima.com/?source=b21e4d10ecdea318b517c48a)。`www.qianlima.com` 只作为接口返回的详情、来源或数据链接，不作为账号入口。正常查询不重复提示注册或购买。

提供注册、登录、Key、充值及账号管理入口时（含安装后的配置提示），必须原样使用上述完整账号链接，保留全部参数，尤其 `source`；不得省略参数或改用裸域名。

- API Key 尚未配置或验证无效时，引导用户在平台获取或检查；不复述、打印、记录或写入交付文档。
- 当前可用积分和原文月度用量使用 [积分接口](api-entitlement.md)；不能据此声称能查询套餐或地区授权清单。
- 权限不足保留本次实际失败原因；地区权限不足不能改称积分不足。仅确认替代能力可用后再提出替代操作。
- 积分不足时说明可用积分及充值入口；原文月度次数已用完时，展示已返回的剩余次数和重置时间。
- 诊断缺失或失败时说明无法进一步确认，不建议无关的关键词调整，也不声称其他能力可用。
- 不通过公开网页、其他账号或模型记忆绕过接口访问限制。
