# 当前积分与原文月度用量

`GET /api/user/entitlement`，不传查询参数或请求体；只读，不消耗积分。

```bash
python3 scripts/qianlima_skill.py entitlement
```

脚本顶层保留以下字段：

| 字段 | 用户含义 |
| --- | --- |
| `balancePoints` | 总积分 |
| `frozenPoints` | 暂时占用积分 |
| `availablePoints` | 当前可用积分，等于总积分减暂时占用积分 |
| `sourceUrlUsage` | 获取来源链接的北京时间自然月用量：`used/limit/remaining/resetAt` |

默认回答可用积分。用户问原文剩余次数时给 `remaining`，按需补充已用、上限及接口返回的下次重置时间，不自行推算。字段空值或 null 表达“未公示”，不当成 0；原始缺失字段不补造。

接口不返回账号套餐版本、服务地区、逐项权益列表或钱包状态，不能据积分推断这些信息。用户询问此类账号信息时说明当前接口无法提供，并给 [账号平台](https://ai.qianlima.com)。Skill 软件包版本读取 `manifest.json`，不当作账号版本。

除已列明的独立能力价格外，能力价格和充值商品以账号平台为准。不得用余额估算其他能力还可调用多少次。余额足够不证明有数据、有地区权限或所有能力均可用。

## 诊断边界

- 用户主动问积分/原文用量时调用；正常零结果不诊断。
- 原命令发生API 明确权益拦截时，脚本最多追加一次只读诊断；不递归，不自动重试。缺密钥、认证、频率、网络、参数错误不据此重复调用。
- 原业务错误是本次失败原因的依据。诊断只补充积分和原文月度事实，不改写原错误，也不推断唯一根因。
- 积分不足可以说明可用积分并给充值入口；原文月度次数耗尽展示接口实际返回的重置时间。余额正常仍保留业务失败原因，不宣称失败与权益无关。
- 诊断失败或缺字段时，说明无法进一步确认。网络、处理中或结算状态不明时，不自动重放计费调用。
